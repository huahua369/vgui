# VGUI 可视化 UI 编辑器重建规划

> 状态：U0 文档模型、U1 运行时挂载、U2 独立工作台和 U3 交付目录已实现。工作台目标为 `vgui_ui_designer`，打包/校验目标为 `vgui_ui_pack`。本规划不替代 [editor kit 组件路线图](editor_roadmap.md)，不改变 `vgui_editor_kit`、`<vgui/vgui_editor.h>` 或 `vgui_game_editor`。

## 1. 目标与取舍

新编辑器用于搭建 **VGUI 界面**（应用面板、表单、HUD），不是游戏场景编辑器。首期跑通一条路径：新建文档 → 放置控件 → 编辑结构和属性 → 检查不同视口下的运行时布局 → 撤销、保存、重新打开。按工作流增加能力，不以覆盖 `vgui.h` 的全部 setter 为目标。

旧原型把控件字段、JSON、C++ 导出、属性检查器和预览同步集中在 `gui/ui_editor.cpp`，同一个属性要在多个分支里分别维护；文档与选择还暴露可变的节点指针。重建不沿用这套接口：**文档是唯一可持久化的事实来源，预览控件树是可丢弃的派生结果，所有编辑走文档事务**。先保证模型正确，再分别实现工具界面和导出。

首期不做自由变换画布、任意插件或脚本、动画时间线、协同编辑、源码反向导入和 WYSIWYG 富文本编辑。运行时只依赖 VGUI；不用编辑器宿主来运行导出的界面。

## 2. 分层与依赖

以下目录和目标名为提案，不预占现有公共 API。先用内部 C++ 接口验证，暂不发布编辑器专属 C ABI。

| 模块 | 责任 | 依赖约束 |
| --- | --- | --- |
| `ui_design_model` | 文档、稳定节点 ID、控件与属性描述表、校验、编辑命令和 JSON 编解码 | 不依赖 VGUI 控件树、窗口或 GPU；可独立运行测试 |
| `ui_design_runtime` | 将通过校验的文档挂载到 `vgui_context`；资源和 action 由宿主解析；提供节点 ID 到预览控件的映射及布局快照 | 只依赖模型和 VGUI 公共接口，不依赖 editor kit 或 SDL |
| `vgui_ui_designer` | SDL3 宿主、面板、画板切换、选择/拖放、文件对话框、诊断 | 复用 Dock、Outliner、PropertyGrid 和命令设施；不把场景模型、3D 视口或 game editor 外壳搬过来 |
| `ui_design_export` | 生成和校验可搬移的设计文档、资源副本与清单 | 只依赖文档模型，不依赖 shell 或活的预览控件，不读取用户机器上的工具状态 |

依赖方向为宿主 → 运行时 → 模型；导出只向下依赖。节点/属性描述表统一定义稳定的 `type_key` / `property_key`、值类型、默认值、约束、可用容器、检查器提示；运行时为这些键提供适配。测不准或做不到往返的属性不要先暴露在面板里。默认值有版本语义，不随编辑器主题或底层控件升级悄悄改变。

## 3. 文档、编辑事务与兼容

- **格式**：建议 `.vgui.json`，`format: "vgui-ui-design"`、`version: 1`、`root` 为稳定节点 ID。`nodes` 以 ID 为键，每个节点包含 `type`、可选显示名、`props` 和有序的 `children` ID 数组。父索引由 `children` 推导，不序列化指针；排序以 `children` 为准，不以 JSON 对象顺序为准。`resources` 用逻辑键映射项目相对路径；文本/l10n 和行为用数据键及 action ID，JSON 不执行代码。
- **校验**：解析到临时文档，校验版本、唯一 ID、有且仅有一个根、单父级、引用存在、无环/孤儿、允许的父子关系、值类型和资源路径，再替换当前文档。未知格式、未来版本、未知节点类型或属性给出带节点 ID/字段路径的诊断，不静默丢字段、不覆盖原文件。加载入口限制文件大小、深度和节点数；资源拒绝逃离项目目录。工具会话（Dock、缩放、选择）不写进交付文档。
- **事务**：新增、删除、复制、同父重排、重挂父级、改属性均以 ID 和具体差异表达。先验证整笔命令，再更新文档、撤销历史和预览；拖动只在提交时记一条，Esc 或焦点丢失时撤销临时反馈。禁止属性面板与画板分别维护撤销栈。保存点由文档历史标识跟踪，撤销回保存点应恢复干净状态；无效操作不得污染历史。
- **保存与迁移**：验证后同目录临时写入，成功后用平台支持的替换方法更新目标，失败保留旧文件及未保存状态。首期不直接打开旧 `vgui-ui-editor` v1 或自动覆盖旧文档；如确认有存量，再做一个显式的单向导入器，带导入报告、保留原件。本次不删除用户本地 JSON 或生成文件。

## 4. 工作台与真实预览

1. **组件库 / 大纲 / 属性 / 画板**：组件库只列已注册控件；大纲负责选择、层级与顺序；属性面板按描述表生成，并显示属性错误；画板提供缩放、平移、屏幕尺寸预设以及选中轮廓。启动只需这四个区域和一个状态/诊断入口。
2. **布局优先**：Row/Column 里的拖拽走插入位/重排，编辑 gap、padding、grow、对齐；只有 Absolute 容器支持拖动 XY 和改尺寸。跨容器拖放先验证目标，再提交一次重挂父级；不把 Flex 排版结果反写成绝对坐标。画布缩放不改变内容视口的逻辑尺寸，也不改文档。
3. **一个布局真相**：通过 VGUI 真实布局计算矩形、裁剪和基线。首期允许完整重建预览；纯属性更新先走适配器，结构变更分阶段优化，不先许诺所有变更都能原地重挂。用独立预览 `vgui_context`；SDL3 宿主可复用现有离屏渲染目标显示预览，模型和挂载测试仍可 headless 跑。预览结果记录文档 revision 与坐标变换，外壳选框/命中只使用同一轮布局快照；旧快照不驱动编辑。
4. **设计/运行模式**：设计模式拦截选区和拖放操作；运行模式将转换过的输入交给预览控件，按钮、焦点、编辑框和滚动按真实运行时工作。预览中的临时输入值不直接写回文档；切回设计时从文档恢复。Preview 与导出使用相同资源键、逻辑尺寸和控件默认值，不为编辑器另写布局引擎。

## 6. U0 实施记录

- [`ui_design_model`](../gui/ui_design/model.h) 是内部 C++ 目标，启用 `VGUI_BUILD_SAMPLES` 时构建；不链接 VGUI、SDL 或 editor kit。从 `session::current()` 读取只读文档，使用 `apply()` 提交一批编辑，再用 `undo()` / `redo()` 回放受影响节点与资源的差异。失败和无实际变化的批次不添加历史；保存成功才移动保存点。
- V1 支持 Panel、Label、Button、Edit、Image，仅 Panel 能容纳子节点。节点与资源键使用不超过 64 字节的 ASCII 字母、数字、点、连字符或下划线。文件上限 4 MiB，最多 4096 节点和 4096 资源；JSON 嵌套上限 32，控件树深度上限 64。资源只登记规范的项目相对路径，不加载文件；U1 的资源解析器还需检查实际解析目标（含符号链接）没有越出项目根目录。
- JSON 与文件读取在全部校验通过后才替换当前文档；保存先写同目录临时文件，再原子替换。旧 `vgui-ui-editor` 原型文件不会被当作 V1 文档读入。
- 无窗口验证：`cmake --build <build-dir> --target ui_design_model_test`，然后 `ctest --test-dir <build-dir> -R '^ui_design_model$' --output-on-failure`。完整和 Core-only 配置均可运行。

最小示例（`props` 中省略的字段使用 V1 描述表默认值）：

```json
{
  "format": "vgui-ui-design",
  "version": 1,
  "root": "form",
  "nodes": {
    "form": {"type": "panel", "props": {"layout": "column"}, "children": ["title"]},
    "title": {"type": "label", "props": {"text": "Settings"}}
  }
}
```

## 7. U1 实施记录

- [`ui_design_runtime`](../gui/ui_design/runtime.h) 使用专用 VGUI context 挂载经过校验的文档，支持五种基础控件及 Absolute/Row/Column；以节点 ID 查询控件，并从真实 VGUI 布局生成带 revision 和 serial 的像素矩形快照。重挂载完整重建子树；无效文档不替换旧树。
- 图片由宿主回调加载；加载前检查规范路径及符号链接目标是否在项目根目录下，失败时显示占位并提供诊断。宿主须保证检查和加载期间目录稳定。按钮激活调用 action 回调；预览中的临时编辑不回写文档，重挂载恢复文档值。context 必须比 runtime 活得更久。
- 无窗口验证：构建 `ui_design_runtime_test` 并运行 `ctest --test-dir <build-dir> -R '^ui_design_runtime(_links)?$' --output-on-failure`。覆盖两种视口宽度、1×/2× DPI、按钮动作及运行态隔离。资源用例从磁盘读取测试像素并挂载 CPU 纹理，验证同键每次挂载只加载一次、缺失或无效图片显示占位、目录不传给加载器，以及拒绝 `..` 路径时保留原树。独立的链接用例验证内部链接可加载，指向同名前缀的相邻目录则不会调用宿主加载器；Windows 使用目录联接，其他平台使用目录符号链接。文件系统不支持创建链接时仅跳过链接用例。

## 8. U2 独立工作台

在完整 SDL3 构建（`VGUI_BUILD_SAMPLES=ON`、`VGUI_BUILD_EDITOR_KIT=ON`）中构建：

```sh
cmake --build <build-dir> --target vgui_ui_designer
```

运行 `vgui_ui_designer` 创建空白文档，或传入 [`sample/res/form.vgui.json`](../sample/res/form.vgui.json) 打开带图片的响应式表单。Windows Debug 可从仓库根目录执行 `out/bin/x64d/vgui_ui_designer.exe sample/res/form.vgui.json`。

### 界面语言

首次启动默认使用**简体中文**。打开 **工具 → 语言**（英文界面为 **Tools → Language**），选择 **简体中文** 或 **English**，界面立即更新，无需重启。选择会保存为下次启动的偏好，不会保存或修改当前设计，也不会重置画板或撤销历史。

偏好保存在 SDL 用户配置目录 `vgui/ui_designer` 下的 `settings.json`（Windows：`%APPDATA%\vgui\ui_designer\settings.json`）。也可用 `VGUI_DESIGNER_SETTINGS` 指定另一个文件（所在目录须已存在）。配置示例：

```json
{
  "language": "zh-CN"
}
```

英文使用 `en-US`。文件缺失、语言未设置、语言代码未知或 JSON 损坏时，编辑器都使用简体中文；读取不会改写文件。保存配置失败时会提示错误并保留当前语言；损坏的 JSON 需先修复。界面文案来自 [简体中文](../sample/res/ui-designer/zh-CN.json) 和 [英文](../sample/res/ui-designer/en-US.json) 语言包，随构建内嵌；改动语言包后需要重新构建。如果新增中文字符，请按[字体说明](../sample/res/fonts/README-DesignerSansSC.md)更新随附的界面字体。画板中的文档文本、动作 ID 与本地化键不随编辑器语言变化。

### 基本操作

顶部主菜单依次为 **文件、编辑、资源、视图、工具、帮助**。按 **F10** 打开主菜单，方向键浏览，Enter 确认，Esc 关闭。

1. 从 **资源 → 新建控件** 添加面板、标签、按钮、输入框或图片。选中容器时添加子节点，选中叶控件时添加同级节点。左侧大纲负责选择、拖放和结构操作；**编辑** 菜单也提供复制、删除和上下移动。操作经由同一文档撤销历史。
2. 在 **Inspector** 修改尺寸、文本、布局、对齐等属性。文本和数值在输入有效时立即更新画板，不必按回车；无效的中间输入保留最后一个有效值。同一字段连续输入只产生一条撤销记录，按 Esc 可取消本次输入。添加图片前建议先把文档保存到项目目录，然后填写 `Image path`，例如 `images/logo.png`（PNG/JPEG，以文档目录为根，使用 `/`）。已登记相对资源时，**Save As** 不允许移到其他目录，以免静默改变资源含义。
3. **预览（Preview）** 提供桌面/平板/手机预设、缩放与中键平移。用 **+**、**−** 或滚轮缩放（运行模式下按住 **Ctrl** 滚动）时，跨过 100% 会先停在 **100%**；下一次缩放可继续。点 **1:1** 可直接回到 **100%** 并将画板居中；点 **适应（Fit）** 则缩放至整个画板可见。在 **Design** 中，直属父容器为 Absolute 的非根控件可用左键拖动；选中后拖四角手柄改变尺寸。拖动中只显示临时轮廓，松手提交一笔修改；Esc 或失焦取消。Row/Column 中的控件仍按布局排版，结构拖放在大纲中操作。**Run** 中使用真实输入交互，切回 **Design** 恢复文档值。切换尺寸预设、缩放和平移都不改文档。
4. **文件** 菜单提供新建页面、打开页面、保存、另存为、关闭页面和退出。新建或打开会保留已有页面；点击画板上方的标签即可切换。同一文件重复打开时激活原标签。保存和导出仅作用于发起操作的页面；关闭或退出有未保存修改的页面时，可选保存、放弃或取消。

编辑器默认按需渲染：窗口静止且无动画时不提交窗口画面，也不重新生成预览纹理。窗口重绘可复用未变化的预览；编辑、缩放、窗口尺寸变化及有焦点的输入动画仍会更新。

- `ui_designer_workbench` 用真实 VGUI 输入测试嵌套结构、属性和图片路径、撤销/重做及保存重开（Core-only 也可运行）。大纲用例覆盖同父重排、跨容器重挂、拒绝非容器与成环目标、Esc 取消，并断言放手前不改文档、合法拖放只需一次撤销。
- `ui_designer_native` 检查连续空闲帧无窗口提交或预览重建、窗口重新暴露时复用预览、空闲期间收到文件选择结果时恢复重绘，以及原生画板、图片、桌面/手机尺寸和打开失败后的文档保留。SDL 运行态用例覆盖 UTF-8 输入、键盘焦点、失焦取消、按钮动作和切回设计后恢复原值；设计态用例覆盖嵌套绝对定位控件的移动、缩放后用右下/左上手柄改尺寸、一次撤销/重做、Esc/失焦取消，以及根节点和流式子控件不被改写。无可用 Vulkan 或原生窗口时只跳过此项。

可以打开 [`sample/res/absolute-form.vgui.json`](../sample/res/absolute-form.vgui.json) 试拖嵌套 Absolute 容器里的控件。

## 9. U3 交付文档与资源清单

**在工作台**：选择 **文件 → 导出交付包（File → Export Package）**，或点击顶部导出快捷按钮，选择一个已存在的父目录，在弹窗里填写新目录名并点击 **导出（Export）**。导出使用当前文档（包括未保存的修改），不会保存原文档、改变当前路径、清除未保存标记或修改撤销历史。

**在命令行**：`vgui_ui_pack export` 读取磁盘上**已保存**的 `.vgui.json`，无需启动工作台。完整或 Core-only 构建均可使用；关闭样例时单独开启 `VGUI_BUILD_UI_DESIGN=ON`。两种方式生成相同格式的交付包，均可用 `vgui_ui_pack verify` 校验。

```sh
cmake --build <build-dir> --target vgui_ui_pack
vgui_ui_pack export sample/res/form.vgui.json out/contact-delivery
vgui_ui_pack verify out/contact-delivery
```

目标目录必须尚不存在，父目录须已存在。导出以设计文件的父目录解析项目资源（尚未保存的工作台文档使用启动时的工作目录）；缺失、非普通文件或解析后越出项目根的资源会拒绝出包。两种方式都不会修改原文档或资源，也不会覆盖已有的交付目录。

`ui_designer_native` 通过 SDL 输入测试工作台导出：输入新目录名、取消、拒绝路径和同名目录，并校验包内的未保存修改及资源；导出前后核对原文件与撤销历史。测试模拟系统目录选择器的返回结果。

交付目录中包括：

- `design.vgui.json`：规范化的 V1 文档，保留节点结构、顺序、属性、动作 ID 与资源键；仅将资源路径改为本包的 `assets/…` 相对路径。
- `resources.vgui.json`：`vgui-ui-delivery` V1 清单，包含设计文档与每个已登记资源的相对路径、字节数和小写十六进制 SHA-256。相同文档与资源字节生成相同产物，不记录时间或工作区路径。
- `assets/`（有资源时）：按资源键顺序命名的普通文件副本，不携带项目中的符号链接。

`verify` 检查设计文档的模型约束和规范字节，重算清单并比较；缺失、篡改或清单不一致时返回非零。清单校验用于检查完整性，不是签名或来源认证，也不解码图片；解码及 action/localization 的实现仍由使用方决定。复制/移动整个交付目录后可直接验证。交付目录需在校验和后续加载期间保持不变。

独立 C++ 宿主可用 `add_subdirectory` 引入本库，关闭样例与 editor kit、开启 `VGUI_BUILD_UI_DESIGN`（需要无 SDL 时再启用 `VGUI_CORE_ONLY`），链接**构建树内部目标** `vgui::ui_design_export` 和 `vgui::ui_design_runtime`。先调用 `read_delivery(directory, doc, &error)`，成功后将同一目录传入 `runtime_bindings::project_root` 并挂载 `doc`。运行时使用和预览相同的 VGUI 布局，不需要编辑器外壳。本阶段不生成 C++ 源码，也不发布新的安装包 ABI。

## 10. U4-A 顶部菜单与多页面工作台

已完成六类主菜单与多页面标签：同窗口可新建、打开、切换和关闭多个页面，当前操作见 §8–9。全部保存和跨页文件流程的扩展回归是下一步。

### 顶部结构

```text
文件   编辑   资源   视图   工具   帮助                         [保存] [导出交付包]
┌─ 大纲 ────┬─ [ 登录页 ● × ] [ 设置页 × ] [ 未命名 1 × ] ─────┬─ 属性检查器 ─┐
│           │  当前页画板：设备 · 缩放 · 设计 / 运行              │               │
└───────────┴────────────────────────────────────────────────────┴───────────────┘
```

- 主菜单固定为这六类；深色顶栏贴合窗口内容区顶部，使用无边框的直角矩形底色。左侧菜单用低强调样式，右侧只保留保存和导出两项可选快捷按钮，窄窗口先收起快捷按钮，六类菜单仍可访问。页面名称显示在画板上方的标签中，不再占用全局顶栏。标签突出活动页和未保存状态；更多标签可横向滚动查看。长名称省略和完整路径提示仍待完善。
- **页面不是控件**：新页面走 **文件 → 新建页面**；控件一律走 **资源 → 新建控件**，左侧不再保留另一套“新建控件”按钮。复制已有节点仍属于编辑操作。
- 菜单、快捷按钮和快捷键使用同一命令注册表与启用条件；不按翻译后的文案识别命令。复用 `VGUI_MENUBAR` / `VGUI_MENU`，支持键盘导航和 Esc 关闭；界面继续默认简体中文，切换语言即时刷新菜单、提示及未命名页，不翻译磁盘文件名。编辑框获得焦点时优先处理自身的编辑快捷键。

| 菜单 | 条目与归属 |
| --- | --- |
| **文件** | 新建页面、打开页面；保存、另存为、关闭页面、导出当前页交付包、退出。打开或新建不会替换正在编辑的页面；全部保存留到后续。 |
| **编辑** | 撤销、重做；复制节点、删除节点、上移、下移。操作只作用于活动页；不支持时禁用而不是静默执行。 |
| **资源** | **新建控件 → 面板、标签、按钮、输入框、图片**。从控件描述表生成菜单，将来新增的控件也只在这里注册。选中容器时添加子节点，选中叶节点时添加同级节点；没有活动页时禁用。导入素材、资源库和组件复用留到后续，不加入空入口。 |
| **视图** | 设计 / 运行、桌面 / 平板 / 手机视口、适应画板、实际大小（100%）。常用视口和缩放操作仍可在画板旁直接使用；页签获得焦点后可用方向键切换。 |
| **工具** | 界面语言（简体中文 / English）。校验仍使用现有 `vgui_ui_pack verify`；是否接入图形入口留待后续。 |
| **帮助** | 操作说明、快捷键、关于。快捷键说明从同一命令定义读取；不把未实现功能列为可用项。 |

### 多页面标签与文件行为

- **一标签一页面文件**：每个标签对应独立 `.vgui.json`，可同时打开、交替编辑；任一时刻只有一个活动页接收输入。每页持有稳定的会话 ID、路径、资源根、文档事务和保存点。切页保留选中节点、设备预设、缩放和平移；大纲、检查器和画板随活动页切换。默认只挂载活动页的预览。切页前将有效的属性编辑提交给原页，取消未提交的画板拖动并结束鼠标捕获和 IME；运行模式里的临时输入不进入文档，切回该页时从设计值重新预览。页签顺序不是文档数据。
- **打开与另存为**：先验证再创建标签；无效文件或取消对话框不影响现有标签。重复打开同一文件只激活原标签；未命名页分配独立编号。同名但不同路径可并存；另存为不能覆盖另一个已打开标签的文件，也不能绕过现有相对资源根约束。
- **保存、关闭与退出**：保存只写目标页，计划中的全部保存会依次处理脏页，未命名页逐个选择路径；取消或保存失败时停止，其余未保存页保持原状，之前已成功保存的页面不会回滚。关闭脏页时可选保存、放弃或取消：选择保存则成功后关闭，明确放弃则不写文件直接关闭，取消或失败保留标签。退出逐页确认，在仍可取消时不销毁任何待放弃的页面。关掉最后一页显示空工作区，保留打开和新建入口。
- **导出与异步**：导出仅取命令发起页的设计快照（含未保存编辑）与其资源根，不改变其保存点，也不合并其他页。文件对话框、保存/关闭确认和几何提交都绑定发起的会话 ID；回调不能仅凭“当前页”或单个 revision 写入。收到旧页的输入、拖动或预览回调时，确认会话 ID 与布局版本仍匹配，否则丢弃。
- **兼容边界**：不改 V1 JSON、运行时挂载和 U3 输出，不引入项目清单、跨页组件链接或打包全部页面。首期不自动恢复上次打开的标签，不把工作台状态写回页面文件。

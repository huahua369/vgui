# VGUI 可视化 UI 编辑器重建规划

> 状态：U0 文档模型、U1 运行时挂载、U2 独立工作台和 U3 交付目录已实现。工作台目标为 `vgui_ui_designer`，打包/校验目标为 `vgui_ui_pack`。本规划不替代 [editor kit 组件路线图](editor_roadmap.md)，不改变 `vgui_editor_kit`、`<vgui/vgui_editor.h>` 或 `vgui_game_editor`。

## 1. 目标与取舍

新编辑器用于搭建 **VGUI 界面**（应用面板、表单、HUD），不是游戏场景编辑器。首期跑通一条路径：新建文档 → 放置控件 → 编辑结构和属性 → 检查不同视口下的运行时布局 → 撤销、保存、重新打开。按工作流增加能力，不以覆盖 `vgui.h` 的全部 setter 为目标。

旧原型把控件字段、JSON、C++ 导出、属性检查器和预览同步集中在 `gui/ui_editor.cpp`，同一个属性要在多个分支里分别维护；文档与选择还暴露可变的节点指针。重建不沿用这套接口：**文档是唯一可持久化的事实来源，预览控件树是可丢弃的派生结果，所有编辑走文档事务**。先保证模型正确，再分别实现工具界面和导出。

首期不做自由变换画布、任意插件或脚本、动画时间线、协同编辑、源码反向导入和 WYSIWYG 富文本编辑。运行时只依赖 VGUI；不用编辑器宿主来运行导出的界面。

## 2. 分层与依赖

以下目录和目标名为提案，不预占现有公共 API。先用内部 C++ 接口验证，暂不发布编辑器专属 C ABI。

| 模块 | 责任 | 依赖约束 |
| --- | --- | --- |
| `ui_design_model` | 文档、稳定节点 ID、控件与属性描述表、校验、编辑命令和 JSON 编解码 | 不依赖 VGUI 控件树、窗口或 GPU；可独立运行测试 |
| `ui_design_runtime` | 将通过校验的文档挂载到 `vgui_context`；资源和 action 由宿主解析；提供节点 ID 到预览控件的映射及布局快照 | 只依赖模型和 VGUI 公共接口，不依赖 editor kit 或 SDL |
| `vgui_ui_designer` | SDL3 宿主、面板、画板切换、选择/拖放、文件对话框、诊断 | 复用 Dock、Outliner、PropertyGrid 和命令设施；不把场景模型、3D 视口或 game editor 外壳搬过来 |
| `ui_design_export` | 生成和校验可搬移的设计文档、资源副本与清单 | 只依赖文档模型，不依赖 shell 或活的预览控件，不读取用户机器上的工具状态 |

依赖方向为宿主 → 运行时 → 模型；导出只向下依赖。节点/属性描述表统一定义稳定的 `type_key` / `property_key`、值类型、默认值、约束、可用容器、检查器提示；运行时为这些键提供适配。测不准或做不到往返的属性不要先暴露在面板里。默认值有版本语义，不随编辑器主题或底层控件升级悄悄改变。

## 3. 文档、编辑事务与兼容

- **格式**：建议 `.vgui.json`，`format: "vgui-ui-design"`、`version: 1`、`root` 为稳定节点 ID。`nodes` 以 ID 为键，每个节点包含 `type`、可选显示名、`props` 和有序的 `children` ID 数组。父索引由 `children` 推导，不序列化指针；排序以 `children` 为准，不以 JSON 对象顺序为准。`resources` 用逻辑键映射项目相对路径；文本/l10n 和行为用数据键及 action ID，JSON 不执行代码。
- **校验**：解析到临时文档，校验版本、唯一 ID、有且仅有一个根、单父级、引用存在、无环/孤儿、允许的父子关系、值类型和资源路径，再替换当前文档。未知格式、未来版本、未知节点类型或属性给出带节点 ID/字段路径的诊断，不静默丢字段、不覆盖原文件。加载入口限制文件大小、深度和节点数；资源拒绝逃离项目目录。工具会话（Dock、缩放、选择）不写进交付文档。
- **事务**：新增、删除、复制、同父重排、重挂父级、改属性均以 ID 和具体差异表达。先验证整笔命令，再更新文档、撤销历史和预览；拖动只在提交时记一条，Esc 或焦点丢失时撤销临时反馈。禁止属性面板与画板分别维护撤销栈。保存点由文档历史标识跟踪，撤销回保存点应恢复干净状态；无效操作不得污染历史。
- **保存与迁移**：验证后同目录临时写入，成功后用平台支持的替换方法更新目标，失败保留旧文件及未保存状态。首期不直接打开旧 `vgui-ui-editor` v1 或自动覆盖旧文档；如确认有存量，再做一个显式的单向导入器，带导入报告、保留原件。本次不删除用户本地 JSON 或生成文件。

## 4. 工作台与真实预览

1. **组件库 / 大纲 / 属性 / 画板**：组件库只列已注册控件；大纲负责选择、层级与顺序；属性面板按描述表生成，并显示属性错误；画板提供缩放、平移、屏幕尺寸预设以及选中轮廓。启动只需这四个区域和一个状态/诊断入口。
2. **布局优先**：Row/Column 里的拖拽走插入位/重排，编辑 gap、padding、grow、对齐；只有 Absolute 容器支持拖动 XY 和改尺寸。跨容器拖放先验证目标，再提交一次重挂父级；不把 Flex 排版结果反写成绝对坐标。画布缩放不改变内容视口的逻辑尺寸，也不改文档。
3. **一个布局真相**：通过 VGUI 真实布局计算矩形、裁剪和基线。首期允许完整重建预览；纯属性更新先走适配器，结构变更分阶段优化，不先许诺所有变更都能原地重挂。用独立预览 `vgui_context`；SDL3 宿主可复用现有离屏渲染目标显示预览，模型和挂载测试仍可 headless 跑。预览结果记录文档 revision 与坐标变换，外壳选框/命中只使用同一轮布局快照；旧快照不驱动编辑。
4. **设计/运行模式**：设计模式拦截选区和拖放操作；运行模式将转换过的输入交给预览控件，按钮、焦点、编辑框和滚动按真实运行时工作。预览中的临时输入值不直接写回文档；切回设计时从文档恢复。Preview 与导出使用相同资源键、逻辑尺寸和控件默认值，不为编辑器另写布局引擎。

| U2：可操作编辑器（MVP） | SDL3 工作台、大纲与检查器、画板、设计/运行切换、文件新建/打开/保存及未保存提示 | 原生端到端：创作带嵌套布局和图片的表单、改属性和重排、撤销、保存重开；小视口不把响应式布局转绝对定位；取消/错误导入不损坏文档 |

| U4-A：菜单与多页面工作台 | 六类主菜单、资源菜单统一创建控件、同窗口打开和编辑多个页面 | 菜单与快捷键共用命令；两页的编辑、资源、保存点、撤销和预览互不串页；继续使用 V1 页面文件和 U3 交付格式 |
| U4-B：扩展 | 组件复用/主题令牌、更多控件、数据绑定、富文本与行内图、必要时旧版单向导入 | 每类扩展补数据往返、预览与导出一致性；性能先做基线（大纲/选取/拖动/重建），再按实际瓶颈增量化 |

## 6. U0 实施记录

- [`ui_design_model`](../gui/ui_design/model.h) 是内部 C++ 目标，启用 `VGUI_BUILD_SAMPLES` 时构建；不链接 VGUI、SDL 或 editor kit。从 `session::current()` 读取只读文档，使用 `apply()` 提交一批编辑，再用 `undo()` / `redo()` 回放受影响节点与资源的差异。失败和无实际变化的批次不添加历史；保存成功才移动保存点。
- V1 支持 Panel、Label、Button、Edit、Image，仅 Panel 能容纳子节点。节点与资源键使用不超过 64 字节的 ASCII 字母、数字、点、连字符或下划线。文件上限 4 MiB，最多 4096 节点和 4096 资源；JSON 嵌套上限 32，控件树深度上限 64。资源只登记规范的项目相对路径，不加载文件；U1 的资源解析器还需检查实际解析目标（含符号链接）没有越出项目根目录。
- JSON 与文件读取在全部校验通过后才替换当前文档；保存先写同目录临时文件，再原子替换。旧 `vgui-ui-editor` 原型文件不会被当作 V1 文档读入。
- 无窗口验证：`cmake --build <build-dir> --target ui_design_model_test`，然后 `ctest --test-dir <build-dir> -R '^ui_design_model$' --output-on-failure`。完整和 Core-only 配置均可运行。

最小示例（`props` 中省略的字段使用 V1 描述表默认值）：

```json
{
  "format": "vgui-ui-design",
  "version": 1,
  "root": "form",
  "nodes": {
    "form": {"type": "panel", "props": {"layout": "column"}, "children": ["title"]},
    "title": {"type": "label", "props": {"text": "Settings"}}
  }
}
```

## 7. U1 实施记录

- [`ui_design_runtime`](../gui/ui_design/runtime.h) 使用专用 VGUI context 挂载经过校验的文档，支持五种基础控件及 Absolute/Row/Column；以节点 ID 查询控件，并从真实 VGUI 布局生成带 revision 和 serial 的像素矩形快照。重挂载完整重建子树；无效文档不替换旧树。
- 图片由宿主回调加载；加载前检查规范路径及符号链接目标是否在项目根目录下，失败时显示占位并提供诊断。宿主须保证检查和加载期间目录稳定。按钮激活调用 action 回调；预览中的临时编辑不回写文档，重挂载恢复文档值。context 必须比 runtime 活得更久。
- 无窗口验证：构建 `ui_design_runtime_test` 并运行 `ctest --test-dir <build-dir> -R '^ui_design_runtime(_links)?$' --output-on-failure`。覆盖两种视口宽度、1×/2× DPI、按钮动作及运行态隔离。资源用例从磁盘读取测试像素并挂载 CPU 纹理，验证同键每次挂载只加载一次、缺失或无效图片显示占位、目录不传给加载器，以及拒绝 `..` 路径时保留原树。独立的链接用例验证内部链接可加载，指向同名前缀的相邻目录则不会调用宿主加载器；Windows 使用目录联接，其他平台使用目录符号链接。文件系统不支持创建链接时仅跳过链接用例。

## 8. U2 独立工作台

在完整 SDL3 构建（`VGUI_BUILD_SAMPLES=ON`、`VGUI_BUILD_EDITOR_KIT=ON`）中构建：

```sh
cmake --build <build-dir> --target vgui_ui_designer
```

运行 `vgui_ui_designer` 创建空白文档，或传入 [`sample/res/form.vgui.json`](../sample/res/form.vgui.json) 打开不依赖外部资源的响应式表单。Windows Debug 可从仓库根目录执行 `out/bin/x64d/vgui_ui_designer.exe sample/res/form.vgui.json`。

### 界面语言

首次启动默认使用**简体中文**。打开 **工具 → 语言**（英文界面为 **Tools → Language**），选择 **简体中文** 或 **English**，界面立即更新，无需重启。选择会保存为下次启动的偏好，不会保存或修改当前设计，也不会重置画板或撤销历史。

偏好保存在 SDL 用户配置目录 `vgui/ui_designer` 下的 `settings.json`（Windows：`%APPDATA%\vgui\ui_designer\settings.json`）。也可用 `VGUI_DESIGNER_SETTINGS` 指定另一个文件（所在目录须已存在）。配置示例：

```json
{
  "language": "zh-CN",
  "layout": { "left_width": 300, "right_width": 380 }
}
```

英文使用 `en-US`。文件缺失、语言未设置、语言代码未知或 JSON 损坏时，编辑器都使用简体中文；读取不会改写文件。保存配置失败时会提示错误并保留当前语言；损坏的 JSON 需先修复。界面文案来自 [简体中文](../sample/res/ui-designer/zh-CN.json) 和 [英文](../sample/res/ui-designer/en-US.json) 语言包，随构建内嵌；改动语言包后需要重新构建。属性输入框和画板共用[随附中文回退字体](../sample/res/fonts/README-DesignerSansSC.md)，可以显示「鞋子」等未出现在界面文案中的文字，不需要安装系统中文字体。画板中的文档文本、动作 ID 与本地化键不随编辑器语言变化。

### 基本操作

顶部主菜单依次为 **文件、编辑、资源、视图、工具、帮助**。按 **F10** 打开主菜单，方向键浏览，Enter 确认，Esc 关闭。

大纲和属性检查器可独立折叠：点击各自标题栏的箭头，折叠后的窄边栏保留展开按钮，并按停靠顺序自上而下竖排显示能容纳的页签名称。高度不足时隐藏放不下的页签，不出现滚动条。点击名称可选中页签，点击顶部箭头展开。也可从 **视图 → 大纲／属性检查器** 切换。折叠会把空间让给画板，展开会恢复该侧上次使用的宽度。

左右分隔条可横向拖动：左侧调整大纲，右侧调整属性检查器。侧栏太窄时，大纲操作区和属性检查器各自显示横向滚动条，避免继续压缩按钮；大纲树的节点过长时也会单独出现水平滚动条；树和底部操作区各自滚动，互不影响。宽度和折叠状态会保存到用户配置的 `layout` 中，下次启动自动恢复；默认两侧均展开，宽度分别为 240 和 345 逻辑像素。**视图 → 恢复默认布局** 会重新展开两侧、恢复默认宽度并保存，不影响页面、选中控件或画板缩放。窄窗口可临时缩小面板，不会覆盖首选宽度。调整工作台布局不会修改页面文档。

1. 从 **资源 → 新建控件** 添加面板、标签、按钮、输入框或图片。新建尺寸（宽 × 高，逻辑像素）分别为 **240 × 160、120 × 24、120 × 36、200 × 36、128 × 128**，可在属性检查器中修改；旧文档与 `0` 表示自动尺寸的规则不变。选中容器时添加子节点，选中叶控件时添加同级节点。左侧大纲负责选择、拖放和结构操作；**编辑** 菜单也提供复制、删除和上下移动。操作经由同一文档撤销历史。
2. 在 **Inspector** 修改尺寸、文本、布局、对齐等属性。文本和数值在输入有效时立即更新画板，不必按回车；无效的中间输入保留最后一个有效值。同一字段连续输入只产生一条撤销记录，按 Esc 可取消本次输入。添加图片前建议先把文档保存到项目目录，然后填写 `Image path`，例如 `images/logo.png`（PNG/JPEG，以文档目录为根，使用 `/`）。已登记相对资源时，**Save As** 不允许移到其他目录，以免静默改变资源含义。
3. 每个页面的画板提供桌面/平板/手机预设、缩放与中键平移。用 **+**、**−** 或滚轮缩放（运行模式下按住 **Ctrl** 滚动）时，跨过 100% 会先停在 **100%**；下一次缩放可继续。点 **1:1** 可直接回到 **100%** 并将画板居中；点 **适应（Fit）** 则缩放至整个画板可见。在 **Design** 中，直属父容器为 Absolute 的非根控件可用左键拖动；选中后拖四角手柄改变尺寸。拖动中只显示临时轮廓，松手提交一笔修改；Esc 或失焦取消。Row/Column 中的控件仍按布局排版，结构拖放在大纲中操作。**Run** 中使用真实输入交互，切回 **Design** 恢复文档值。切换尺寸预设、缩放和平移都不改文档。
4. **文件** 菜单提供新建页面、打开页面、保存、另存为、全部保存、关闭页面和退出。新建或打开会保留已有页面；点击画板上方的页面名称即可切换。沿标签栏拖动可排序，向画板区域拖出可浮动；拖动浮动面板的页面标题回标签栏即可归位。同一文件重复打开时激活原页面。单页保存和导出只作用于发起操作的页面。**全部保存**先按标签顺序保存有修改的停靠页，再处理浮动页；未命名页逐一选择路径，不切换活动标签。取消或遇到错误时停止，已保存的页面不回滚。关闭或退出有未保存修改的页面时，可选保存、放弃或取消。

选中标签、按钮或输入框后，可在属性检查器的 **字体** 分组调整字体族、字号、字重、字形和文字颜色；画板即时应用，设置写入页面 JSON。字号 `0` 沿用默认值，自定义范围为 **4–256 逻辑像素**。输入框的占位文字同样使用所选字体族、字号和字形，颜色仍由主题提供。旧页面未设置这些属性时维持原外观。

属性检查器用带底色的输入框区分可编辑值与只读文本。文字颜色既可以输入 `#RRGGBB` 或 `#RRGGBBAA`，也可以点击旁边的色块打开拾色器；调整时画板同步预览，点弹层外应用本次修改，按 Esc 取消。清空颜色或点击恢复默认按钮可使用主题色。

**字体族**可选默认、内置 DejaVu Sans、内置 Designer Sans SC（中文优先）或项目字体。先保存页面，然后选择 **资源 → 导入项目字体**，选择一个单字体 `.ttf` 或 `.otf` 文件（不超过 32 MiB）。项目外的字体复制到页面所在目录的 `fonts/` 下，同名不会覆盖；项目内的字体只登记原有相对路径。导入后在控件的字体族列表中选择它，并保存页面。撤销导入只撤销资源登记，不删除磁盘文件。预览使用内置字体补齐缺失字符；字体不可读或达到当前编辑器会话的缓存上限（32 个项目字体版本、总计 64 MiB）时，回退为默认并提示。交付包包含登记过的项目字体，不写入系统路径；导出前请确认字体许可证允许再分发。使用 C++ 运行时的宿主可通过 `runtime_bindings::load_font` 提供对应的字体族及回退链。

编辑器默认按需渲染：窗口静止且无动画时不提交窗口画面，也不重新生成预览纹理。窗口重绘可复用未变化的预览；编辑、缩放、窗口尺寸变化及有焦点的输入动画仍会更新。主窗口和离屏画板默认请求 **8× MSAA**；显卡不支持时，使用它支持的最高档位（4×、2× 或 1×）。

- `ui_designer_workbench` 用真实 VGUI 输入测试嵌套结构、属性和图片路径、撤销/重做及保存重开（Core-only 也可运行）。大纲用例覆盖同父重排、跨容器重挂、拒绝非容器与成环目标、Esc 取消，并断言放手前不改文档、合法拖放只需一次撤销。
- `ui_designer_native` 检查连续空闲帧无窗口提交或预览重建、窗口重新暴露时复用预览、空闲期间收到文件选择结果时恢复重绘，以及原生画板、图片、桌面/手机尺寸和打开失败后的文档保留。SDL 运行态用例覆盖 UTF-8 输入、键盘焦点、失焦取消、按钮动作和切回设计后恢复原值；设计态用例覆盖嵌套绝对定位控件的移动、缩放后用右下/左上手柄改尺寸、一次撤销/重做、Esc/失焦取消，以及根节点和流式子控件不被改写。无可用 Vulkan 或原生窗口时只跳过此项。

可以打开 [`sample/res/absolute-form.vgui.json`](../sample/res/absolute-form.vgui.json) 试拖嵌套 Absolute 容器里的控件。

### 图片按钮示例

在 **文件 → 打开页面** 中打开 [`sample/res/image-button.vgui.json`](../sample/res/image-button.vgui.json)，切到 **运行（Run）**。左边是可交互按钮，移动鼠标、按住左键、松开可观察普通、悬停和按下状态；右边始终显示禁用状态。左边按钮激活后会在状态栏显示 `demo.play` 动作。

这是普通按钮的可选皮肤，不是新的控件类型。选择按钮后，在属性检查器填写 **四态图集路径**（相对于页面文件，示例为 `image-button-states.png`），清空则恢复普通按钮外观。图集宽高必须为偶数；无法加载时预览会报告问题并使用普通按钮外观。[示例图集](../sample/res/image-button-states.png) 是一张 **384 × 128** 的透明 PNG，每帧 **192 × 64**。从左上角开始依次为普通 `(0, 0)`、悬停 `(192, 0)`、按下 `(0, 64)`、禁用 `(192, 64)`。每次只绘制其中一帧，文字、键盘焦点和动作仍由按钮处理。导出交付包时整张图集作为一个资源交付。

### 拟物化控件示例

在编辑器中打开 [skeuomorphic-controls.vgui.json](../sample/res/skeuomorphic-controls.vgui.json)，切换到 **运行**，悬停或按住按钮看状态变化。三组控件可以在设计态分别拆开修改：

- **按钮**：科技蓝、夕阳红、森林绿三种原生渐变预设，另有禁用对照和四态图集。属性检查器的 **外观 → 按钮样式** 设为 **渐变** 后，**渐变预设** 才会生效。不指定预设时保持原来的深灰样式。
- **面板**：中央卡片使用原生纵向渐变，内槽使用横向渐变。左右卡片的金属底板改用独立的四个色标渐变图层。
- **进度条**：生命、能量、经验值仍是真实进度条；圆角外框和带 Alpha 色标的表面高光是独立装饰，移除后不影响数值和读数。进度条本身仍使用纯色填充。
- 只有用于演示图片皮肤的四态按钮仍引用图集；底板和高光不再占用图片资源。

选择渐变按钮后，可展开属性检查器的 **渐变颜色** 分组，分别覆盖普通、悬停、按下的顶色和底色，以及高光边和阴影边。颜色支持 `#RRGGBB` / `#RRGGBBAA`；留空或重置即跟随当前预设，色块显示继承值，拾色器也从该颜色开始。切回纯色只隐藏这些字段，不删除原有设置。若按钮设有可用的四态图集，仍优先绘制图集。示例中的「完成」按钮展示了自定义配色。

在 JSON 的按钮 `props` 中可使用 `gradient_normal_top` / `gradient_normal_bottom`、`gradient_hover_top` / `gradient_hover_bottom`、`gradient_pressed_top` / `gradient_pressed_bottom`、`gradient_border_light` / `gradient_border_dark`。可只写需要修改的一项，例如 `"button_style": "gradient", "gradient_preset": "blue", "gradient_border_light": "#C0E2FF"`。

面板在 **外观 → 背景样式** 选择 **渐变** 后，可在 **渐变颜色** 中设置方向、起始色和结束色（支持透明度）。未填的端点使用默认蓝灰色；切回 **纯色** 时恢复原背景色，并保留渐变参数。背景覆盖整个圆角面板，滚动只移动内容。

```json
{
  "background_style": "gradient",
  "background_gradient_direction": "horizontal",
  "background_gradient_start": "#465B70",
  "background_gradient_end": "#1A2431"
}
```

### 装饰渐变控件

在 **资源 → 新建控件 → 渐变** 创建。设计态可选中、移动和改尺寸；运行态不接收鼠标、触摸或键盘焦点，叠在按钮上也不会挡住输入。它没有子控件，不需要资源键。在 **渐变填充** 切换类型，点击「色标」预览条打开编辑器；弹窗显示当前色标数量，按偏移排列的滚动列表可精确选中相邻色标。调整偏移、颜色和透明度会实时预览，点外部提交，Esc 取消。

- **线性**：起点、终点；**径向**：内外两圆的圆心和半径、椭圆（横向 2:1）；**扫掠（圆锥）**：中心和起止角。坐标以控件左上角为 `(0,0)`、右下角为 `(1,1)`；半径用短边比例。径向焦点遵循 OVG 的外圆范围限制。扫掠从右侧起顺时针计角，用 `0 → 360` 填满一圈，交换起止角反向，不自动跨越接缝。
- **延展**：延用端点颜色、重复、镜像重复。OVG 当前把 `NONE` 按钳制处理，没有独立的区间外透明模式；纹理滤镜不会影响程序化渐变，网格渐变也未实现，不在检查器中提供无效选项。
- **仿射、圆角和边框**：`gradient_affine_xx/yx/xy/yy/tx/ty` 六个系数只变换渐变填充，不变换控件轮廓；圆角和边框作为独立外观属性。透明度同时可设在单个色标和整个控件上。
- **JSON**：新增叶节点 `type: "gradient"`；`gradient_stops` 为包含 2–32 个 `{ "offset": 0, "color": "#FFFFFF40" }` 对象的数组。色标位置在 0–1，按升序排列并留出至少 0.0001 的间距。

#### 扫光与变色

打开 [gradient-animation.vgui.json](../sample/res/gradient-animation.vgui.json)。选中渐变控件，在 **渐变动画 → 动画效果** 选 **扫光** 或 **变色**。切到 **运行** 自动播放；切回 **设计** 恢复原始渐变，下次进入运行时从头开始。没有动画的页面不显示播放栏。

- **暂停 / 播放**停在当前帧或继续，**重播**从头开始。点击或拖动进度条会暂停，并同时定位整页的动画。右侧显示当前时间和可拖动的范围。
- 进度条的范围宽度取页面中最长的动画时长。有循环动画时，播放越过右端会移到下一个时间区间；各动画保留自己的周期，单次动画到结尾后不再变化。只有单次动画的页面播到最后会自动暂停。
- 每个页签独立保留播放位置和暂停状态，不可见的页签不推进。播放栏只控制预览，不写回文档，也不产生撤销记录。

| JSON 属性 | 默认值 | 含义 |
|---|---|---|
| `gradient_animation` | `"none"` | `"shine"` 扫光，`"color"` 变色 |
| `gradient_animation_duration` | `2` | 总时长，0.1–60 秒。循环变色时包括去程和回程 |
| `gradient_animation_loop` | `true` | 扫光从头重复；变色往返播放。关闭时只播一次 |
| `gradient_animation_dx` / `gradient_animation_dy` | `2` / `0` | 扫光总位移，以控件宽／高为单位，原渐变位置是中点。让高光两端透明，循环接缝不显眼 |
| `gradient_animation_color` | `"#70BFFF"` | 变色目标，接受 `#RRGGBB` / `#RRGGBBAA`。以预乘 Alpha、线性光做颜色插值；仍保留原色标的透明度分布 |

动画属性随文档保存和导出。宿主可在 `layout()` 之后、绘制之前每帧调用 `ui_design::runtime::advance_animations(dt)`（`dt` 以秒计），隐藏或超出视口的图层暂停推进。需要绝对时间预览时，可以读取 `animation_timing()` 并调用 `seek_animations(seconds)`；这会在给定时刻采样可见图层。不调用这些接口则保持原始渐变。采样只改当前画笔，不写回 JSON、不重建控件。

#### 渐变关键帧与多轨时间轴

打开 [gradient-keyframes.vgui.json](../sample/res/gradient-keyframes.vgui.json)，点击画板工具栏的 **渐变时间轴**。将任意渐变控件的 **渐变动画 → 动画效果** 设为 **关键帧**，它就会在画板下方出现一条轨道。扫光和变色预设仍可分别使用，不需要迁移旧页面。

- 点击轨道名称后，在当前时间点点 **添加关键帧**；也可以双击轨道空白处直接添加。新关键帧从原始渐变的姿态开始。选中菱形后可修改 X/Y 相对位移、乘色染色、不透明度和插值方式。白色染色不改变原色，不透明度 1 保留原透明度。
- 时间轴顶部可直接修改所选渐变轨道的 **时长** 和 **循环**，关键帧使用归一化偏移，因此改时长会保持相对节奏；时间轴、播放栏和画布预览会立即同步。
- 拖动菱形调整时刻，使用 **删除关键帧** 删除所选帧。每次拖动、添加、删除或属性提交都能用页面的撤销/重做恢复。滚轮查看更多轨道，Ctrl+滚轮缩放，**适应时长**重置时间尺。
- 在时间轴内按 Ctrl/Shift 点选或在空白处拖动框选，可同时选择多帧（支持跨轨道）。下方的「不同值」表示所选帧的该属性不一致。修改 X/Y、染色、不透明度或插值只覆盖所选帧中本次编辑的属性；每次提交可整批撤销。
- 用 **复制 / 粘贴**（时间轴聚焦时也可按 Ctrl+C / Ctrl+V）。最早的一帧对齐播放头，其余帧保留秒数间隔和完整姿态。单轨复制粘贴到所选轨道，多轨复制按原轨道分配。遇到重叠、越界、轨道不存在或超出数量/位移限制时整批不粘贴，不覆盖原帧。剪贴板仅用于当前页的时间轴，不写入 JSON。
- 拖动时间尺或选中关键帧会暂停并查看对应画面；播放栏可继续播放。下方时间轴编辑首轮的关键帧，各轨道仍按各自的时长播放。切回 **设计** 恢复原始渐变。

**用示例试一次保存和交付**：先另存一份实验台。在「移动高光」轨道约 0.7 秒处添加一帧，将不透明度设为 `0.5`，复制后再粘贴到约 1.6 秒处。撤销应只移除粘贴的新帧，重做应恢复它；另开同一示例的第二份副本时不能粘贴第一份的关键帧。将「移动高光」改为 3.6 秒并关闭循环，保存后重新打开，关键帧保留相对位置。目录包和单文件 JSON 都携带这些已编辑的关键帧、时长与循环设置，不需要图片资源。

`ui_designer_native` 驱动原生工作台的鼠标、文本输入和菜单，验证跨页剪贴板、撤销/重做、保存和两种交付格式；再从验包后的文档采样渐变，比较粘贴帧与单次播放结束后的不透明度。`ui_designer_gradient_keyframes` 则无需窗口，单独覆盖时间轴输入、多轨选择、姿态编辑和粘贴边界。

`gradient_animation: "keyframes"` 使用 `gradient_animation_keyframes` 数组。每帧包含 `offset`（相对时长，0–1）、`x` / `y`（以控件宽高为单位的相对位移）、`tint`（`#RRGGBB` 乘色）、`opacity`（0–1，不透明度倍率）和 `interpolation`（从此帧到下一帧的 `step`、`linear` 或 `smooth`）。最多 128 帧、按偏移严格递增，每条轨道独立循环或停在末帧。使用归一化时间可在修改总时长时保留相对节奏；时间轴展开状态与预览位置不写入 JSON。画笔移动不改变控件边界，不支持轮廓变形。

**形状关键帧**：打开 [gradient-geometry.vgui.json](../sample/res/gradient-geometry.vgui.json)，展开渐变时间轴，选中关键帧后点击 **形状…**。线性渐变显示起点和终点；径向渐变显示内外圆心和半径；扫掠渐变显示中心和起止角。可以对选中的多帧一起修改；不同类型混选时只显示共同支持的参数。「原值」表示沿用该控件的渐变属性，「还原」会删除当前字段的关键帧覆盖。形状值也随关键帧复制、粘贴、撤销和导出。

| 类型 | 关键帧可选 JSON 字段 |
| --- | --- |
| 线性 | `start_x`、`start_y`、`end_x`、`end_y` |
| 径向 | `center_x`、`center_y`（内圆心）、`outer_x`、`outer_y`（外圆心）、`inner_radius`、`outer_radius` |
| 扫掠 | `center_x`、`center_y`、`start_angle`、`end_angle` |

坐标沿用渐变属性的相对坐标系，允许 −16 到 16；半径为控件短边的倍数，允许 0–16；起止角为 0–360°，按数值插值，不自动跨接缝。字段缺省时使用控件的原值再插值；当前类型不使用的字段保留而不生效。线性两端或扫掠两角不能在关键帧重合，径向关键帧的外半径必须大于内半径。如果插值中间因重合或浮点舍入出现无效形状，则该时刻用控件原形状，位移、染色、不透明度仍正常采样。半径动画只改变色场，不改变控件轮廓。

**色标关键帧**：在时间轴单选一帧，点 **色标…**，选择一个色标后可改颜色、不透明度和偏移。「使用原色标」会清除整组覆盖，回到该控件的静态色标。示例中的线性轨道同时改变中间色标和渐变端点。

JSON 中每帧可选 `stops`，内容是和 `gradient_stops` 同样的 `[{"offset":0.25,"color":"#66CCFF80"}, …]` 数组。播放按顺序一一对应色标；动画内不能增删、交换色标，复制到其他轨道时色标数量必须匹配。若要改控件的色标数量，先清除带色标的关键帧覆盖。缺省的 `stops` 沿用静态色标，旧文档无需转换。偏移随该帧的阶跃、线性或平滑插值；颜色按线性光和预乘 Alpha 插值，再应用整帧乘色及不透明度。

## 9. U3 交付文档与资源清单

**在工作台**：选择 **文件 → 导出交付包（File → Export Package）**，或点击顶部导出快捷按钮，先打开可移动的「导出配置」。选择格式、目标目录和包名后点击 **导出**；对话框显示来源页面、资源数量和原始字节数，单文件模式额外显示 Base64 资源体积（不含 JSON 结构）。默认选目录包，默认目标目录为发起页的资源根；可用 **浏览…** 改选位置。导出使用发起时的文档快照（包括未保存的修改），不会保存原文档、改变当前路径、清除未保存标记或修改撤销历史。写入成功后自动重新读取并校验；取消不会创建产物。

- **目录包（默认）**：保持现有格式，支持项目图片和项目字体。
- **单文件 JSON（Base64）**：生成 `*.vgui.package.json`，设计、图片原始字节和 SHA-256 校验信息都在同一个文件里，不需要 `assets/`。包括普通图片、图标和按钮图集，不压缩图片；Base64 数据本身约为原始资源字节数的 4/3。页面引用了项目字体时请改用目录包，不会静默替换字体。这是交付格式，不改写编辑器保存的 `.vgui.json`。

**在命令行**：`vgui_ui_pack export` 读取磁盘上**已保存**的 `.vgui.json`，无需启动工作台。完整或 Core-only 构建均可使用；关闭样例时单独开启 `VGUI_BUILD_UI_DESIGN=ON`。两种方式生成相同格式的交付包，均可用 `vgui_ui_pack verify` 校验。

```sh
cmake --build <build-dir> --target vgui_ui_pack
vgui_ui_pack export sample/res/form.vgui.json out/contact-delivery
vgui_ui_pack verify out/contact-delivery
vgui_ui_pack export --single-json sample/res/control-gallery.vgui.json out/gallery.vgui.package.json
vgui_ui_pack verify out/gallery.vgui.package.json
```

输出文件或目录必须尚不存在，父目录须已存在。导出以设计文件的父目录解析项目资源（尚未保存的工作台文档使用启动时的工作目录）；缺失、非普通文件或解析后越出项目根的资源会拒绝出包。两种格式都不会修改原文档或资源，也不会覆盖已有产物。

`ui_designer_native` 通过 SDL 输入测试工作台的配置切换、目录选择及取消、包名验证、拒绝覆盖与跨页单文件导出；系统目录选择器的返回结果由测试模拟。

交付目录中包括：

- `design.vgui.json`：规范化的 V1 文档，保留节点结构、顺序、属性、动作 ID 与资源键；仅将资源路径改为本包的 `assets/…` 相对路径。
- `resources.vgui.json`：`vgui-ui-delivery` V1 清单，包含设计文档与每个已登记资源的相对路径、字节数和小写十六进制 SHA-256。相同文档与资源字节生成相同产物，不记录时间或工作区路径。
- `assets/`（有资源时）：按资源键顺序命名的普通文件副本，不携带项目中的符号链接。

`verify` 检查设计文档的模型约束和规范字节，重算并比较 SHA-256；单文件包还严格检查 Base64 及解码后长度，保留规范 V1 设计文字的散列。缺失、篡改或清单不一致时返回非零。单文件包上限 96 MiB（图片原始字节累计上限 64 MiB）；超过时请使用目录包。这是完整性检查，不是签名或来源认证；校验不会解码 PNG/JPEG，也不会把内嵌资源写到磁盘。交付产物需在校验和加载期间保持不变。

独立 C++ 宿主可用 `add_subdirectory` 引入本库，关闭样例与 editor kit、开启 `VGUI_BUILD_UI_DESIGN`（需要无 SDL 时再启用 `VGUI_CORE_ONLY`），链接**构建树内部目标** `vgui::ui_design_export` 和 `vgui::ui_design_runtime`。目录包调用 `read_delivery(directory, doc, &error)`，成功后将同一目录传入 `runtime_bindings::project_root`；单文件包调用 `read_json_delivery(file, package, &error)`，`runtime_bindings::load_embedded_image` 可按资源键从 `package.images` 解码图片，再挂载 `package.design`，无需把图片解包到磁盘。两种方式均不需要编辑器外壳，不引入新的安装包 ABI。

后续配置建议按优先级加入，首版不显示未实现的开关：

1. **资源范围**：全部登记资源（默认）或仅当前页引用；精确提取容器、按钮皮肤、图标及列表/树/菜单内的资源引用，并保留完整性校验。
2. **完成后的操作**：显示实际产物大小，并可手动打开输出位置。后续如需批量使用，再提供可选导出预设；不把导出配置写入源设计。

## 10. U4-A 顶部菜单与多页面工作台

已完成六类主菜单、多页面标签及全部保存：同窗口可新建、打开、切换、关闭和批量保存页面，当前操作见 §8–9。跨页关闭、退出取消与交付隔离已纳入原生回归。

### 顶部结构

```text
文件   编辑   资源   视图   工具   帮助                         [保存] [导出交付包]
┌─ 大纲 ────┬─ [ 登录页 ● × ] [ 设置页 × ] [ 未命名 1 × ] ─────┬─ 属性检查器 ─┐
│           │  当前页画板：设备 · 缩放 · 设计 / 运行              │               │
└───────────┴────────────────────────────────────────────────────┴───────────────┘
```

- 主菜单固定为这六类；深色顶栏贴合窗口内容区顶部，使用无边框的直角矩形底色。左侧菜单用低强调样式，右侧只保留保存和导出两项可选快捷按钮，窄窗口先收起快捷按钮，六类菜单仍可访问。左侧只显示一个“大纲”标题，中间直接以页面名称为页签，不再显示外层“预览”标签。标签突出活动页和未保存状态；更多标签可横向滚动查看。
- **页面不是控件**：新页面走 **文件 → 新建页面**；控件一律走 **资源 → 新建控件**，左侧不再保留另一套“新建控件”按钮。复制已有节点仍属于编辑操作。
- 菜单、快捷按钮和快捷键使用同一命令注册表与启用条件；不按翻译后的文案识别命令。复用 `VGUI_MENUBAR` / `VGUI_MENU`，支持键盘导航和 Esc 关闭；界面继续默认简体中文，切换语言即时刷新菜单、提示及未命名页，不翻译磁盘文件名。编辑框获得焦点时优先处理自身的编辑快捷键。

| 菜单 | 条目与归属 |
| --- | --- |
| **文件** | 新建页面、打开页面；保存、另存为、全部保存、关闭页面、导出当前页交付包、退出。打开或新建不会替换正在编辑的页面；全部保存仅在存在未保存修改时可用。 |
| **编辑** | 撤销、重做；复制节点、删除节点、上移、下移。操作只作用于活动页；不支持时禁用而不是静默执行。 |
| **资源** | **新建控件 → 面板、标签、按钮、输入框、图片**。从控件描述表生成菜单，将来新增的控件也只在这里注册。选中容器时添加子节点，选中叶节点时添加同级节点；没有活动页时禁用。导入素材、资源库和组件复用留到后续，不加入空入口。 |
| **视图** | 设计 / 运行、桌面 / 平板 / 手机视口、适应画板、实际大小（100%）。大纲和属性检查器可独立折叠，恢复默认布局可同时展开两侧。常用视口和缩放操作仍可在画板旁直接使用；页签获得焦点后可用方向键切换。 |
| **工具** | 界面语言（简体中文 / English）。校验仍使用现有 `vgui_ui_pack verify`；是否接入图形入口留待后续。 |
| **帮助** | 操作说明、快捷键、关于。快捷键说明从同一命令定义读取；不把未实现功能列为可用项。 |

### 多页面标签与文件行为

- **一标签一页面文件**：每个标签对应独立 `.vgui.json`，可同时打开、交替编辑；任一时刻只有一个活动页接收输入。每页持有稳定的会话 ID、路径、资源根、文档事务和保存点。切页保留选中节点、设备预设、缩放和平移；大纲和检查器跟随活动页。只渲染可见的停靠页和浮动页，最多缓存一个刚切走的预览以加快往返切页。切页前将有效的属性编辑提交给原页，取消未提交的画板拖动并结束鼠标捕获和 IME；运行模式里的临时输入不进入文档，切回该页时从设计值重新预览。各页签可拖动排序，也可向画板区域拖出成为独立的窗口内浮动面板；拖动其标题可移动，拖回中间标签栏可重新停靠。位置和页签顺序不会写入文档，不创建额外系统窗口。
- **长标题与路径提示**：页签和浮动面板的标题过长时以省略号截断，给未保存标记和关闭按钮留出空间。鼠标停留在标题上时，已有文件路径的页面显示规范化后的完整本地路径，不附加未保存标记或文字；尚无文件路径的页面显示完整标题。悬停可区分不同目录下的同名文件，不会切换活动页或改变未保存状态。
- **打开与另存为**：先验证再创建标签；无效文件或取消对话框不影响现有标签。重复打开同一文件只激活原标签；未命名页分配独立编号。同名但不同路径可并存；另存为不能覆盖另一个已打开标签的文件，也不能绕过现有相对资源根约束。
- **保存、关闭与退出**：保存只写目标页，全部保存与退出确认先按当前页签顺序处理停靠页，再按打开顺序处理浮动页；未命名页逐个选择路径；取消或保存失败时停止，其余未保存页保持原状，之前已成功保存的页面不会回滚。关闭脏页时可选保存、放弃或取消：选择保存则成功后关闭，明确放弃则不写文件直接关闭，取消或失败保留标签。退出逐页确认，在仍可取消时不销毁任何待放弃的页面。关掉最后一页显示空工作区，保留打开和新建入口。
- **导出与异步**：导出仅取命令发起页的设计快照（含未保存编辑）与其资源根，不改变其保存点，也不合并其他页。文件对话框、保存/关闭确认和几何提交都绑定发起的会话 ID；回调不能仅凭“当前页”或单个 revision 写入。收到旧页的输入、拖动或预览回调时，确认会话 ID 与布局版本仍匹配，否则丢弃。
- **兼容边界**：不改 V1 JSON、运行时挂载和 U3 输出，不引入项目清单、跨页组件链接或打包全部页面。首期不自动恢复上次打开的标签，不把工作台状态写回页面文件。

### 编辑器主题

**工具 → 主题** 可直接在深色和浅色之间切换并保存；**工具 → 选项 → 外观** 可预览主题，确定后保存，取消或按 Esc 恢复原主题。偏好保存到同一个设置 JSON 的 `theme` 项（`dark` / `light`），下次启动自动恢复，缺省使用深色。主题只影响编辑器与默认网格配色，不改变页面的控件样式、运行态或用户自定义的网格颜色。

设计模式的网格绘制在页面控件后方，运行模式不显示。新页面的 Root 背景色默认是透明的 `#00000000`；现有页面未指定 Root 背景色时也按透明处理。若要为页面着色又保留网格，在属性检查器调低 Root **背景色**的 Alpha（例如 `#22334480`），无需调低控件整体透明度。显式设置的不透明背景会盖住其下方的网格。

## 11. 声明式控件与属性

**资源 → 新建控件** 现在提供 19 种可声明的核心控件：面板、标签、按钮、输入框、图片、渐变、复选框、单选按钮、开关、滑块、进度条、分隔线、列表、树、菜单、菜单栏、分栏、选项卡和停靠容器。可以打开 [control-gallery.vgui.json](../sample/res/control-gallery.vgui.json)，切到 **运行** 体验控件交互；在 **设计** 中选中控件查看属性。

- **属性检查器**按类型显示内容、字体、几何、布局细节、外观和交互。比如最小/最大尺寸、外边距、Wrap 换行布局、滚动、背景/边框/透明度、提示和无障碍名称。控件还提供自己的初始值和样式，如滑块范围、步长和方向，输入框多行或只读，图片裁剪、着色、翻转、九宫格、旋转和仿射矩阵，按钮四态图集和图标。图集和图标是相互独立的资源。未设置的可选外观继续沿用核心样式，已有 V1 页面不需要迁移。
- **标签（Label）**可在 **属性检查器 → 内容 → 文字方向** 切换 **横排** 和 **竖排（单列）**。页面 JSON 可在标签的 `props` 写入 `"text_orientation": "vertical"`；省略此项或填写 `"horizontal"` 时保持原有横排。竖排从上往下排列字素，文字保持直立，不旋转英文或替换竖排标点字形，也不会自动换列。固定尺寸会裁剪超出的文字；可增加高度，或把高度设为 `0` 使用自动尺寸（仍受父容器布局约束）。打开 [label-orientation.vgui.json](../sample/res/label-orientation.vgui.json)，可对照同一段文字的横排和竖排效果；两种交付包都会保留文字方向。
- **列表、树和菜单**在 **内容 → 初始条目（JSON）** 编辑数组。有效输入立即预览，语法或字段无效时保留上一版有效条目；离开输入框提交一次编辑，Esc 取消。在页面 JSON 中 `items` 也是数组，不是转义后的字符串。
- **分栏**最多接收两个子控件；**选项卡 / 停靠容器**直接接收面板，然后可在面板内放置任意支持的控件。选中子面板时在 **页面** 编辑页签标题、启用状态或停靠区域等设置。要在选项卡上预览另一页，可切到 **运行** 点选，或在设计文件里设置容器的从 0 开始的初始页索引。选项卡的原生关闭会销毁页面，未暴露该操作；Dock 的原生关闭只隐藏页。
- **单选按钮**在 **属性检查器 → 内容 → 组名** 设置所属组（保存为 `radio_group`）。同一直接父容器中，只有组名完全相同的按钮互斥；留空表示默认组，旧页面仍按原规则运行。组名支持中文，不需要改变布局或大纲结构。勾选「初始选中」会自动取消同组原来的选项；将已选中的按钮改到另一组时，该按钮成为新组的初始选项。两项变化可以一步撤销。运行态切换不会写回设计文件。
- **菜单**以单标题入口打开弹层，**菜单栏**可定义多标题；菜单项的 `shortcut` 是显示提示，不自动注册行为。按钮和菜单叶子条目可保存 `action` 键，由宿主处理。

条目示例：

| 控件 | `items` 示例 |
| --- | --- |
| 列表 | `["第一项", {"text":"第二项", "icon":"icons/folder.png", "buttons":[{"icon":"icons/open.png", "action":"row.open"}], "selected":true}]` |
| 树 | `[{"text":"父节点", "expanded":true, "children":[{"text":"子节点"}]}]` |
| 菜单 | `[{"text":"保存", "icon":"icons/save.png", "shortcut":"Ctrl+S", "action":"demo.save"}, {"separator":true}]` |
| 菜单栏 | `[{"text":"文件", "children":[{"text":"保存", "action":"demo.save"}]}]` |

列表和树的条目可设置 `enabled`、`selected`、`text_color`、`tooltip` 和 `icon`，以及最多 4 个 `buttons`。每个按钮可独立设置 `icon` 和 `action`；在运行态点击时，宿主收到控件节点 ID 和动作键，行选中状态不变。无图标按钮沿用原生方块显示。菜单弹出项（包括子菜单入口）也可设置 `icon`；若同时填写 `emoji`，优先显示 `emoji`。

属性检查器中的 `icon` 接受已有资源键或相对于页面文件目录的图片路径，新路径随条目一起登记、保存和撤销。上面的路径示例用于属性检查器；直接编辑页面 JSON 时，`icon` 应引用 `resources` 里的键，不应填写路径。行图标和按钮图标与普通图片共用项目路径检查、预览加载和交付打包。

运行态临时选中值、输入、宿主数据源、自定义绘制、回调和纹理句柄不写入设计文件。原生全局主题配置和自定义渲染仍属于宿主 API。
